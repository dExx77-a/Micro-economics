# Micro Study

A static microeconomics study site: chapter summaries, flashcards, multiple choice and true/false quizzes.

- Add or edit chapters in `data/chapters.js`. No other file needs to change.
- Open `index.html` in a browser to try it locally.

## Publish on GitHub Pages
1. Create a new repository on github.com and upload all of these files to its main branch.
2. Open Settings, then Pages. Under Source choose "Deploy from a branch", pick `main` and `/ (root)`, and save.
3. After a minute the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
